## 搜索模块结构分析

### HTML结构

搜索模块位于每个页面的 header 区域，具体结构如下：

```html
<div class="ast-builder-layout-element ast-flex site-header-focus-item ast-header-search"
    data-section="section-header-search">
    <div class="ast-search-menu-icon slide-search">
        <form role="search" method="get" class="search-form"
            action="https://bergppc.com/">
            <label for="search-field">
                <span class="screen-reader-text">Search for:</span>
                <input type="search" id="search-field" class="search-field"
                    placeholder="Search..." value="" name="s" tabindex="-1">
                <button class="search-submit ast-search-submit"
                    aria-label="Search Submit">
                    <!-- SVG图标 -->
                </button>
            </label>
        </form>
        <div class="ast-search-icon">
            <a class="slide-search astra-search-icon" role="button" tabindex="0"
                aria-label="Search button" href="#">
                <!-- SVG图标 -->
            </a>
        </div>
    </div>
</div>
```

### 特征标记

搜索模块可通过以下特征识别：
- `class="site-header-focus-item ast-header-search"`
- `data-section="section-header-search"`
- `class="ast-search-menu-icon slide-search"`
- `<form role="search" method="get" class="search-form"`

## 删除计划

### 步骤1: 识别所有包含搜索模块的文件

已确认47个HTML文件包含搜索模块。

### 步骤2: 编写批量删除脚本

由于搜索模块结构相对固定（在HTML中的位置和格式一致），可以：
1. 使用 PowerShell 脚本批量处理所有HTML文件
2. 删除整个搜索模块的HTML代码块

### 步骤3: 验证删除结果

检查删除后的文件确保：
- 搜索模块已完全删除
- 页面其他部分保持完整
- HTML结构仍然有效

## 不需要修改的文件

- WordPress 核心文件 (wp-content, wp-includes)
- 主题和插件的 CSS/JS 文件
- Feed 文件 (feed/index.htm 等)
- 图片和字体文件

## 实施步骤

1. **备份文件** (可选但推荐)
2. **编写 PowerShell 脚本**:
   - 定位所有包含 `site-header-focus-item ast-header-search` 的文件
   - 删除从该div开始到对应闭合div的整个代码块
   - 保留周围的HTML结构不变
3. **批量执行**脚本处理所有47个文件
4. **验证结果**: 抽查几个文件确认删除成功

## 技术细节

### 删除范围

删除整个搜索模块div（包括子元素）：
```html
<div class="ast-builder-layout-element ast-flex site-header-focus-item ast-header-search"
    data-section="section-header-search">
    <!-- 整个搜索模块内容 -->
</div>
```

### 保留内容

- 父容器 `<div class="site-header-above-section-right...">` 的开始标签
- 兄弟元素（如有）
- 页面其他所有内容

### 预期结果

- 删除后 header 右侧区域变为空或塌陷
- 不影响页面其他功能
- 保持1:1视觉一致性（仅移除搜索功能区域）
