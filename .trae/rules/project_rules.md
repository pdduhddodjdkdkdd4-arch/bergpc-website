# 项目规则

## Git 分支命名规范

分支名称必须使用以下格式：

```
时间_修改标题总结
```

- **时间**：使用 `YYYYMMDD` 格式，如 `20250611`
- **修改标题总结**：简短描述本次修改内容，使用英文或中文均可，单词间用短横线连接

### 示例

- `20250611_fix-footer-layout`
- `20250612_replace-social-icons`
- `20250615_mysql-migration`
- `20250620_添加律师管理功能`
